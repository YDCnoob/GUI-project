# 삼국지 GUI 프로젝트

Python과 Pygame으로 제작 중인 삼국지 스타일의 턴제 전략 게임 프로젝트입니다.

CLI 형태로 시작한 게임 로직을 GUI 환경으로 옮기면서, 입력 처리와 게임 규칙, 화면 출력을 서로 분리하는 방향으로 구조를 정리하고 있습니다.

현재 버전은 4개의 도시를 기반으로 도시 선택, 내정, 군사, 전투 및 점령, 통치자 임명, 정보 확인, 턴 진행 등의 기본 흐름을 구현한 상태입니다.

---

## 개발 환경

- Python 3
- Pygame
- 기본 해상도: `1024 x 768`
- 창 크기 변경 지원
- 화면 비율을 유지한 확대/축소 적용

Pygame이 설치되어 있지 않다면 다음 명령으로 설치할 수 있습니다.

```bash
pip install pygame
```

---

## 실행 방법

프로젝트 최상위 폴더에서 다음 명령을 실행합니다.

```bash
python pygame_main.py
```

프로젝트 폴더 구조를 유지한 상태에서 실행해야 합니다.

## 프로젝트 구조

```text
project/
├── pygame_main.py
├── ui.py
│
├── core/
│   ├── __init__.py
│   ├── city.py
│   ├── constants.py
│   ├── domestic.py
│   ├── military.py
│   ├── officer.py
│   └── turn.py
│
└── main/
    ├── __init__.py
    ├── city_select.py
    ├── domestic_menu.py
    ├── info_menu.py
    ├── military_menu.py
    └── turn_handler.py
```

### 구조의 기본 원칙

```text
main  = 입력 처리와 메뉴 흐름
core  = 게임 데이터와 실제 게임 규칙
ui    = 화면 출력
```

새로운 기능을 추가할 때도 가능한 한 이 역할을 유지하는 것을 목표로 합니다.

예를 들어 새로운 내정 기능을 만든다면:

```text
main/domestic_menu.py
        ↓
사용자의 선택과 메뉴 흐름 처리
        ↓
core/domestic.py
        ↓
실제 수치 계산 및 도시 데이터 변경
        ↓
ui.py
        ↓
변경된 결과를 화면에 표시
```

## 주요 파일 설명

### `pygame_main.py`

게임의 시작점입니다.

주요 역할:

- Pygame 초기화
- 게임 창 생성
- 게임 상태 변수 관리
- 이벤트 루프 실행
- 현재 메뉴에 맞는 handler 호출
- UI 그리기 함수 호출
- 화면 확대/축소
- FPS 제한

세부 게임 기능은 가능한 한 직접 처리하지 않고 `main/` 또는 `core/`의 함수에 맡기는 구조로 정리하고 있습니다.

### `main/`

키 입력과 화면 간 이동을 담당하는 handler 모듈입니다.

#### `city_select.py`

- 도시 선택
- 점령 도시의 통치자 선택

#### `domestic_menu.py`

- 내정 메뉴 이동
- 농업 개발 실행
- 상업 개발 실행
- 치안 강화 실행
- 내정 결과 팝업 처리

#### `military_menu.py`

- 군사 메뉴 이동
- 모병 수량 입력
- 훈련 실행
- 출진 대상 선택
- 출진 병력 입력
- 전투 결과 처리
- 병력 이동 대상 선택
- 이동 병력 입력

#### `info_menu.py`

- 정보 화면 입력 처리
- `Enter` 또는 `ESC`를 통한 메인 메뉴 복귀

#### `turn_handler.py`

- 플레이어 소유 도시들의 턴 종료 처리
- 도시별 월간 처리 실행
- 군사 행동 제한 초기화
- 행동력 회복
- 날짜 진행
- 턴 결과 팝업 생성

## `core/` 게임 로직

### `city.py`

도시 데이터와 도시 탐색 기능을 담당합니다.

현재 등록된 도시는 다음과 같습니다.

- 성도
- 한중
- 번성
- 강하

도시 데이터에는 다음과 같은 값이 포함됩니다.

```text
통치자
인접 도시
지도 좌표
인구
식량
금
치안
농업
상업
병력
훈련도
행동력
턴별 군사 행동 여부
```

주요 함수:

```python
find_city()
get_neighbor_cities()
```

### `officer.py`

장수 데이터와 세력 관련 기능을 담당합니다.

현재 장수 데이터에는 다음 능력치가 존재합니다.

```text
통솔
무력
지력
정치
매력
```

주요 함수:

```python
find_officer()
get_officers_by_faction()
get_city_faction()
get_faction()
get_available_governors()
```

### `domestic.py`

도시의 내정 및 월간 경제 처리를 담당합니다.

현재 구현된 기능:

- 농업 개발
- 상업 개발
- 치안 강화
- 식량 생산
- 식량 소비
- 식량 부족 시 구매 처리
- 세금 징수
- 인구 증감
- 치안 자연 감소

### `military.py`

군사 관련 실제 게임 규칙을 담당합니다.

현재 구현된 기능:

- 모병
- 훈련
- 전투
- 병력 이동

현재 전투 판정은 기본적으로 공격 병력과 방어 병력의 수를 비교하는 단순한 형태입니다.

### `turn.py`

월 단위 턴 진행을 담당합니다.

한 도시의 턴 처리 시 다음 기능을 순서대로 실행합니다.

```text
식량 생산
→ 식량 소비
→ 치안 감소
→ 세금 징수
→ 인구 변화
```

### `constants.py`

게임 전체에서 사용하는 공통 상수를 관리합니다.

예:

- 최대 행동력
- 기본 인구 성장률
- 시작 연도 / 월
- 모병 비용
- 훈련 비용
- 훈련도 증가량
- 최대 훈련도

## 현재 구현된 게임 기능

### 도시 선택

좌우 방향키를 이용해 도시를 선택할 수 있습니다.

선택한 도시의 기본 정보는 지도 아래 정보창에 표시됩니다.

### 내정

현재 플레이어 세력의 도시에서만 실행할 수 있습니다.

구현된 명령:

- 농업 개발
- 상업 개발
- 치안 강화

내정 명령은 도시의 행동력을 소비합니다.

### 군사

현재 구현된 군사 명령:

- 모병
- 훈련
- 출진
- 병력 이동

일부 군사 행동은 도시별로 한 턴에 한 번만 실행할 수 있습니다.

### 모병

- 숫자 직접 입력 지원
- 좌우 방향키로 100명 단위 조절
- 100명 단위로 모병 가능
- 모병 시 식량 소비

### 훈련

- 도시의 병력을 훈련
- 병력 수에 따라 금 소비
- 훈련도 증가
- 최대 훈련도 제한 존재

### 출진 및 전투

- 인접한 다른 세력 도시만 공격 가능
- 출진 병력 직접 입력 가능
- 100명 단위로 출진
- 승리 시 목표 도시 점령
- 패배 시 생존 병력이 출발 도시로 복귀

### 도시 점령 및 통치자 임명

전투에서 승리하면 점령한 도시의 통치자를 선택합니다.

플레이어 세력 소속이며 현재 다른 도시의 통치자로 사용되지 않는 장수 중에서 선택할 수 있습니다.

점령 직후 해당 도시는 행동력이 `0`이 되며 다음 턴에 회복됩니다.

### 병력 이동

- 인접한 같은 세력 도시로만 이동 가능
- 이동 병력 직접 입력 가능
- 100명 단위로 이동

### 정보 메뉴

현재 선택한 도시의 상세 정보와 통치자 정보를 확인할 수 있습니다.

도시 정보:

- 인구
- 금
- 식량
- 치안
- 농업
- 상업
- 병력
- 훈련도

통치자 정보:

- 이름
- 세력
- 통솔
- 무력
- 지력
- 정치
- 매력

통치자가 없는 도시도 표시할 수 있습니다.

### 턴 종료

턴을 종료하면 플레이어 소유 도시를 대상으로 월간 처리가 실행됩니다.

- 식량 생산 및 소비
- 세금 징수
- 인구 변화
- 치안 변화
- 군사 행동 제한 초기화
- 행동력 회복
- 날짜 1개월 진행

처리가 끝난 뒤 전체 식량 생산량, 세금 수입, 인구 변화가 팝업으로 표시됩니다.

## 기본 조작

### 메인 메뉴

| 키 | 기능 |
|---|---|
| `←` / `→` | 메뉴 이동 |
| `Enter` | 선택 |

### 세부 메뉴

| 키 | 기능 |
|---|---|
| `↑` / `↓` | 항목 선택 |
| `Enter` | 결정 |
| `ESC` | 취소 / 이전 화면 |

### 병력 수 입력

| 키 | 기능 |
|---|---|
| 숫자키 | 수량 직접 입력 |
| `Backspace` | 한 자리 삭제 |
| `←` / `→` | 100명 단위 감소 / 증가 |
| `Enter` | 실행 |
| `ESC` | 취소 |

### 정보 화면

| 키 | 기능 |
|---|---|
| `Enter` | 메인 메뉴 복귀 |
| `ESC` | 메인 메뉴 복귀 |

```text
  ↓

  ↓

```

```text
      └── ui/     : 화면 출력
```

## 개발 방향

이 프로젝트는 기능을 한 파일에 집중시키기보다 각 함수와 모듈의 역할을 나누는 방향으로 개발하고 있습니다.

기본 원칙:

> 한 함수는 하나의 명확한 책임을 갖도록 한다.

예를 들어 군사 메뉴 handler는 사용자의 입력과 화면 전환을 담당하고, 실제 전투 계산은 `core/military.py`가 담당합니다.

이 구조를 유지하면서 게임 시스템을 단계적으로 확장할 예정입니다.
