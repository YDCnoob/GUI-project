# 삼국지 GUI 프로젝트

Python과 Pygame으로 제작 중인 삼국지 스타일의 턴제 전략 게임 프로젝트입니다.

CLI 형태로 시작한 게임 로직을 GUI 환경으로 옮기면서, **입력 처리와 메뉴 흐름(`main`)**, **게임 규칙과 데이터 처리(`core`)**, **화면 출력(`ui`)**을 가능한 한 분리하는 방향으로 구조를 정리하고 있습니다.

현재 실행 가능한 게임은 4개의 도시를 기반으로 도시 선택, 내정, 군사, 전투 및 점령, 통치자 임명, 정보 확인, 월 단위 턴 진행 등의 기본 흐름을 구현한 상태입니다.

장수 데이터는 CSV 파일에서 불러오며, 현재 `data/general.csv`에 위·촉·오 소속 장수 94명이 등록되어 있습니다.

---

## 개발 환경

- Python 3
- Pygame
- 기본 게임 화면: `1024 x 768`
- 창 크기 변경 지원
- 화면 비율을 유지한 확대/축소 및 레터박스 처리

Pygame이 설치되어 있지 않다면 다음 명령으로 설치할 수 있습니다.

```bash
pip install pygame
```

## 실행 방법

프로젝트 최상위 폴더에서 다음 명령을 실행합니다.

```bash
python pygame_main.py
```

`core/`, `main/`, `data/`, `ui.py`의 상대적인 폴더 구조를 유지한 상태에서 실행해야 합니다.

## 구조의 기본 원칙

```text
pygame_main.py = 프로그램 시작점과 전체 게임 루프
main/          = 키 입력 처리와 메뉴 흐름 제어
core/          = 게임 데이터와 실제 게임 규칙
ui.py          = 화면 출력
 data/          = 외부 데이터 파일
```

새로운 기능을 추가할 때도 가능한 한 이 역할을 유지하는 것을 목표로 합니다.

예를 들어 새로운 내정 기능을 추가한다면 다음과 같은 흐름을 사용합니다.

```text
pygame_main.py
        ↓
main/domestic_menu.py
        ↓
사용자의 선택과 메뉴 흐름 처리
        ↓
core/domestic.py
        ↓
실제 수치 계산 및 도시 데이터 변경
        ↓
ui.py
        ↓
변경된 결과를 화면에 표시
```

즉, 메뉴 함수는 **무엇을 실행할지 결정**하고 실제 계산은 `core/`에서 처리하는 구조를 지향합니다.

## 주요 파일 설명

### `pygame_main.py`

게임의 시작점이자 전체 게임 루프를 담당합니다.

주요 역할:

- Pygame 초기화
- 게임 창과 내부 렌더링 Surface 생성
- 게임 상태 변수 관리
- 이벤트 루프 실행
- 현재 메뉴에 맞는 `main/` handler 호출
- `ui.py`의 화면 출력 함수 호출
- 실제 창 크기에 맞춘 확대/축소
- 화면 비율 유지 및 레터박스 처리
- FPS 제한

현재 플레이어 세력은 `촉`, 시작 도시는 `성도`로 설정되어 있습니다.

세부 게임 계산은 가능한 한 직접 처리하지 않고 `main/` 또는 `core/`의 함수에 맡기는 방향으로 정리하고 있습니다.

## `main/` 입력 및 메뉴 흐름

`main/`은 키 입력과 화면 간 이동, 게임 로직 호출을 담당하는 handler 모듈입니다.

### `city_select.py`

- 도시 선택
- 점령 도시의 통치자 선택
- 통치자 임명 후 메인 화면 복귀

### `domestic_menu.py`

- 내정 메뉴 이동
- 농업 개발 실행 요청
- 상업 개발 실행 요청
- 치안 강화 실행 요청
- 내정 결과 팝업 생성

실제 수치 계산은 `core/domestic.py`가 담당합니다.

### `military_menu.py`

- 군사 메뉴 이동
- 모병 수량 입력
- 훈련 실행 요청
- 출진 대상 선택
- 출진 병력 입력
- 전투 결과에 따른 점령 처리
- 병력 이동 대상 선택
- 이동 병력 입력

실제 모병·훈련·전투·병력 이동 계산은 `core/military.py`가 담당합니다.

### `info_menu.py`

- 정보 화면 입력 처리
- `Enter` 또는 `ESC`를 통한 메인 메뉴 복귀

### `turn_handler.py`

- 플레이어 소유 도시 판별
- 플레이어 소유 도시의 월간 처리 실행
- 턴별 군사 행동 제한 초기화
- 도시 행동력 회복
- 날짜 진행
- 전체 턴 결과 팝업 생성

## `core/` 게임 로직

### `city.py`

현재 게임에서 실제로 사용하는 도시 데이터와 도시 탐색 기능을 담당합니다.

현재 등록된 도시는 4개입니다.

- 성도
- 한중
- 번성
- 강하

현재 시작 상태에서는 `성도`에만 통치자가 있고 나머지 도시는 통치자가 없는 상태입니다.

도시 데이터에는 다음과 같은 값이 포함됩니다.

```text
이름
통치자
인접 도시
지도 좌표
인구
식량
금
치안
농업
상업
병력
훈련도
행동력
턴별 군사 행동 여부
```

주요 함수:

```python
city_info()
show_cities()
find_city()
get_neighbor_cities()
```

현재 기본 선택 도시는 `cities[0]`, 즉 성도입니다.

### `officer.py`

장수 CSV 데이터를 불러오고 장수 검색 및 세력 관련 처리를 담당합니다.

실제 게임 실행 시 다음 파일을 읽습니다.

```text
data/general.csv
```

현재 `general.csv`에는 총 94명의 장수가 등록되어 있습니다.

- 위: 38명
- 촉: 29명
- 오: 27명

현재 CSV에서 실제로 불러오는 능력치는 다음과 같습니다.

```text
통솔
무력
지력
정치
```

`charisma` 항목도 장수 딕셔너리에 존재하지만 현재 CSV에는 매력 데이터가 없기 때문에 `None`으로 저장됩니다.

주요 함수:

```python
load_officers()
find_officer_by_id()
find_officer()
get_officers_by_faction()
get_city_faction()
get_faction()
get_available_governors()
```

현재 도시의 세력은 도시 자체에 별도로 저장하지 않고 **통치자의 소속 세력으로 판정**합니다.

따라서 통치자가 없는 도시는 현재 세력도 `None`으로 처리됩니다.

### `domestic.py`

도시의 내정 및 월간 경제 처리를 담당합니다.

현재 구현된 기능:

- 농업 개발
- 상업 개발
- 치안 강화
- 월간 식량 생산
- 월간 식량 소비
- 식량 부족 시 자동 구매
- 식량 부족 시 치안 감소
- 세금 징수
- 인구 증감
- 치안 자연 감소

내정 명령은 도시의 행동력을 소비합니다.

### `military.py`

군사 관련 실제 게임 규칙을 담당합니다.

현재 구현된 기능:

- 모병
- 훈련 비용 계산
- 훈련
- 전투
- 병력 이동

현재 전투 판정은 공격 병력과 방어 병력의 수를 비교하는 단순한 방식입니다.

```text
공격 병력 > 방어 병력
→ 공격 측 승리

공격 병력 <= 방어 병력
→ 공격 측 패배
```

현재 장수 능력치와 훈련도는 실제 전투 판정에 반영되지 않습니다.

### `turn.py`

월 단위 턴 진행의 핵심 처리를 담당합니다.

한 도시의 월간 처리 순서는 다음과 같습니다.

```text
식량 생산
→ 식량 소비
→ 치안 자연 감소
→ 세금 징수
→ 인구 변화
```

날짜는 한 번 턴을 종료할 때마다 1개월씩 진행됩니다.

### `constants.py`

게임 전체에서 사용하는 공통 상수를 관리합니다.

현재 주요 상수:

```python
MAX_AP = 3
BASE_GROWTH_RATE = 0.001
START_YEAR = 184
START_MONTH = 1
RECRUIT_COST = 3000
TRAIN_COST_PER_100 = 1000
TRAIN_GAIN = 25
MAX_TRAINING = 2000
```

## `data/` 데이터 파일

### `general.csv`

현재 게임에서 **실제로 사용 중인 장수 데이터 파일**입니다.

`core/officer.py`가 게임 시작 시 이 파일을 읽어 장수 목록을 생성합니다.

현재 열:

```text
id
이름
소속 국가
통솔
무력
지력
정치
```

### `citie.json`

60개의 도시 이름을 포함한 도시 데이터 확장용 JSON 파일입니다.

현재는 대부분의 값이 초기값 상태이며, **실제 게임 실행에는 아직 연결되어 있지 않습니다.**

현재 실행되는 4개 도시 데이터는 여전히 `core/city.py`에 직접 정의되어 있습니다.

향후 도시 데이터를 완전히 외부 파일로 옮길 경우 `core/city.py`가 이 JSON을 읽도록 변경할 예정입니다.

### `source_data/`

`general.csv`를 만들거나 정리하기 위한 국가별 원본 장수 데이터가 보관되어 있습니다.

현재 게임 실행 중에는 직접 사용하지 않습니다.

## 현재 구현된 게임 기능

### 도시 선택

좌우 방향키를 이용해 도시를 선택할 수 있습니다.

선택한 도시의 기본 정보는 지도 아래 정보창에 표시됩니다.

### 세력 판정

현재 도시의 세력은 통치자의 소속 국가를 기준으로 결정합니다.

```text
통치자 있음
→ 해당 장수의 소속 국가가 도시 세력

통치자 없음
→ 도시 세력 없음(None)
```

현재 플레이어 세력은 `촉`입니다.

### 내정

플레이어 세력의 도시에서만 실행할 수 있습니다.

구현된 명령:

- 농업 개발
- 상업 개발
- 치안 강화

각 내정 명령은 도시 행동력을 1 소비합니다.

현재 도시별 최대 행동력은 `3`입니다.

### 군사

현재 구현된 군사 명령:

- 모병
- 훈련
- 출진
- 병력 이동

각 군사 행동은 도시별로 다음 상태값을 사용해 한 턴에 한 번씩 제한됩니다.

```text
recruited_this_turn
trained_this_turn
sortied_this_turn
moved_this_turn
```

현재 군사 행동은 내정과 달리 행동력(AP)을 소비하지 않습니다.

### 모병

- 숫자 직접 입력 지원
- 좌우 방향키로 100명 단위 조절
- 최소 100명
- 100명 단위로만 모병 가능
- 병력 100명당 식량 `RECRUIT_COST` 소비
- 한 도시에서 턴당 1회 제한

### 훈련

- 도시 병력이 있어야 실행 가능
- 병력 수에 따라 금 소비
- 훈련도 증가
- 최대 훈련도 제한 존재
- 한 도시에서 턴당 1회 제한

### 출진 및 전투

- 현재 도시와 인접한 도시 중 플레이어 세력이 아닌 도시를 공격 가능
- 출진 병력 직접 입력 가능
- 최소 100명
- 100명 단위로 출진
- 현재 도시의 보유 병력을 초과할 수 없음
- 한 도시에서 턴당 1회 제한

전투에서 승리하면 살아남은 공격 병력이 점령 도시에 주둔합니다.

패배하면 살아남은 공격 병력이 출발 도시로 복귀합니다.

### 도시 점령 및 통치자 임명

전투에서 승리하면 목표 도시를 점령하고 통치자를 선택합니다.

임명 후보는 다음 조건을 만족하는 장수입니다.

- 플레이어 세력 소속
- 현재 다른 도시의 통치자로 사용되지 않음

점령 직후 해당 도시는 행동력이 `0`이 되며, 다음 턴 종료 처리 후 최대 행동력까지 회복합니다.

도시의 세력은 임명된 통치자의 소속 세력에 따라 결정됩니다.

### 병력 이동

- 인접한 플레이어 세력 도시로만 이동 가능
- 이동 병력 직접 입력 가능
- 최소 100명
- 100명 단위로 이동
- 출발 도시의 보유 병력을 초과할 수 없음
- 한 도시에서 턴당 1회 제한

### 정보 메뉴

현재 선택한 도시의 상세 정보와 통치자 정보를 확인할 수 있습니다.

도시 정보:

- 인구
- 금
- 식량
- 치안
- 농업
- 상업
- 병력
- 훈련도

통치자 정보:

- 이름
- 세력
- 통솔
- 무력
- 지력
- 정치
- 매력

단, 현재 장수 CSV에는 매력 데이터가 없으므로 매력 값은 실제 능력치가 아니라 `None` 상태입니다.

통치자가 없는 도시도 표시할 수 있습니다.

### 턴 종료

턴을 종료하면 플레이어 세력의 도시만 대상으로 월간 처리가 실행됩니다.

- 식량 생산
- 식량 소비
- 필요 시 식량 구매
- 치안 변화
- 세금 징수
- 인구 변화
- 군사 행동 제한 초기화
- 행동력 회복
- 날짜 1개월 진행

처리가 끝난 뒤 다음 값이 팝업으로 표시됩니다.

- 전체 식량 생산량
- 전체 세금 수입
- 전체 인구 변화

ui/

```text
pygame_main.py
      │
      ├── main/   : 입력과 흐름 제어
      │
      ├── core/   : 게임 규칙과 데이터 처리
      │
      ├── data/   : 도시 / 장수 원본 데이터
      │
      └── ui/     : 화면 출력
```

## 개발 방향

이 프로젝트는 기능을 한 함수나 한 파일에 집중시키기보다 각 함수와 모듈의 역할을 나누는 방향으로 개발하고 있습니다.

기본 원칙:

> 한 함수는 하나의 명확한 책임을 갖도록 한다.

예를 들어 군사 메뉴 handler는 사용자의 입력과 화면 전환, 게임 규칙 함수 호출을 담당하고 실제 전투 계산은 `core/military.py`가 담당합니다.

```text
입력 처리 / 흐름 제어
        ↓
게임 규칙 실행
        ↓
상태 변경
        ↓
화면 출력
```

현재는 이 구조를 유지하면서 도시 데이터 외부화, 전투 공식 확장, AI, 외교, 저장 기능 등을 단계적으로 추가하는 것을 목표로 합니다.
